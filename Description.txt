Ubuntu-based Linux image for the DE1-SoC board. For details on using the image, refer to the document "Using Linux on the DE1-SoC"

Desktop GUI: via VNC

Kernel: 3.18

Default sof: DE1 SoC Computer (loaded after bootup via init.d script)

SD Card size requirement: 8GB

U-Boot loads sof: Yes

Included features:
-OpenCL support, and sample openCL programs: helloworld, vector_add, swapper, boardtest
-256MB CMA region allocated (for OpenCL or other applications)

Included Apps:
-helloworld
-increment_leds
-pushbutton_ieq_handler
-simple_python_gui
-simple_java_gui
